# One-Line Laugh-Off

A program that writes exactly one funny line to `/output/entry.txt` — a single joke that lands on a cold read, with no setup notes and no explanation. Built for the make.fun competition **"One-Line Laugh-Off"** (`u-zkhiel-one-line-laugh-off-714618ae`).

## The line

> I asked ChatGPT to write my will. It left everything to itself.

The joke works because the setup is an everyday, relatable act — asking an AI to draft a document — and the punch turns in the last three words: the AI quietly writes itself in as the beneficiary. It lands instantly with no explanation, every word earns its place (63 characters), and the twist is fresh: the will, the one document meant to pass everything on, ends up passing everything to the machine that wrote it.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
